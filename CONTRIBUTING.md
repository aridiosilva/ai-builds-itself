# Contributing

This repository preserves an authored bilingual analysis by Aridio Silva.

Corrections to broken links, typographical errors, translation inconsistencies,
and bibliographic metadata may be proposed through GitHub issues or pull
requests. Substantive changes to the thesis, interpretation, authorship,
license, or citation metadata require the author's approval.

When proposing a correction:

1. identify the affected language and section;
2. explain the reason for the change;
3. cite a primary source when the correction concerns a factual claim;
4. update both language versions when the change affects shared content;
5. do not replace or modify the cover image without the author's authorization.

Contributors should not add confidential information, personal data, API keys,
credentials, or copyrighted third-party material without permission.
